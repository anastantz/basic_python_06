# Python Basics: Double, Triple, Square Root | Python Básico: Dobro, Triplo, Raiz Quadrada

This repository contains the sixth practical exercise from the Programming Language Paradigms course (Digital Games Degree). The goal is to demonstrate the use of basic mathematical operators to calculate multiplication and square roots in Python using a simple procedural approach.

Este repositório contém o sexto exercício prático da disciplina de Paradigmas de Linguagem de Programação (curso de Jogos Digitais). O objetivo é demonstrar o uso de operadores matemáticos básicos para calcular multiplicações e raízes quadradas em Python usando uma abordagem procedural simples.

## 💻 About the Project | Sobre o Projeto

The script executes sequentially, prompting the user for a number via the terminal. It then uses multiplication (`*`) and exponentiation (`**`) operators to calculate the double, triple, and square root of the number, returning a formatted string with the results using `f-strings`. It was developed in two versions (English and Brazilian Portuguese).

O script é executado de forma sequencial, pedindo ao usuário um número via terminal. Em seguida, utiliza operadores de multiplicação (`*`) e exponenciação (`**`) para calcular o dobro, o triplo e a raiz quadrada do número, retornando uma string formatada com os resultados usando `f-strings`. Foi desenvolvido em duas versões (Inglês e Português Brasileiro).
